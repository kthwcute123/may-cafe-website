# Mây Café — Website giới thiệu quán cà phê

Website tĩnh, responsive, viết bằng HTML/CSS/JavaScript thuần. Có thể chạy trực tiếp trên trình duyệt hoặc xuất bản bằng GitHub Pages.

## Chạy thử
1. Tải `index.html`.
2. Mở file bằng Chrome, Edge hoặc Firefox.
3. Ảnh sử dụng URL Unsplash và font Google Fonts nên cần internet để hiển thị đầy đủ.

## Tuỳ chỉnh trước khi xuất bản
- Tìm `Mây Café` để đổi tên quán.
- Cập nhật địa chỉ, giờ mở cửa, email, số điện thoại và liên kết mạng xã hội trong phần `#visit` / footer.
- Thay ảnh Unsplash bằng ảnh thật của quán nếu có.
- Giá và thông tin hiện tại là nội dung mẫu; hãy sửa cho đúng thực tế.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub, ví dụ `may-cafe-website` (chọn Public nếu dùng GitHub Free).
2. Upload `index.html` và `README.md` vào thư mục gốc.
3. Vào **Settings → Pages**.
4. Ở **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, rồi Save.
5. Chờ GitHub Pages triển khai, sau đó mở URL hiển thị trong phần Pages.

Lưu ý: website hiện là trang giới thiệu tĩnh; biểu mẫu đặt bàn/đặt món, thanh toán và quản trị cần backend hoặc dịch vụ bổ sung nếu muốn triển khai.
